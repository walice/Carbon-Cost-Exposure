# Data for the replication package

The analysis input `panel_vars.rds` (and its CSV copy) is not tracked in git. Download it from the Harvard Dataverse archive for the article and place it in this folder before running `run_all.R`:

- `panel_vars.rds` — harmonised 7-wave panel, pre-imputation
- `panel_vars.csv` — the same as CSV
- `codebook.csv` — variable documentation (tracked here)

The `derived/` subfolder is created by the scripts.
